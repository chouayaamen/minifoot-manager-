# Product Brief: Mini-Foot Tactical & Roster Manager

## Vision
A web application for amateur mini-football teams (5v5, 6v6, 7v7, 8v8) to manage player self-registration, match RSVPs, dynamic pitch formations, and generate shareable WhatsApp lineup cards.

## Personas

### Manager / Captain
- Creates match formats (5v5, 6v6, 7v7, 8v8)
- Builds pitch lineups using drag-and-drop formation presets
- Logs match stats (goals, assists, cards)
- Manages fixtures and venues
- Exports lineup images for WhatsApp sharing

### Player
- Registers profile with physical specs (height, weight) and tactical specs (primary/secondary position, preferred foot)
- Updates RSVP status for upcoming matches
- Views personal stats on leaderboards
- Receives fixture notifications
